# Esquema XSD de factura SRI

Estos archivos son dependencias de validación del XML de factura antes de
firmarlo y transmitirlo al SRI.

- `factura_V1.1.0.xsd`: descargado del paquete oficial de factura publicado
  en la página de Facturación Electrónica del SRI.
- `xmldsig-core-schema.xsd`: esquema XMLDSig estándar requerido por el XSD de
  factura para validar la estructura de la firma electrónica.

Fuentes:

- https://www.sri.gob.ec/facturacion-electronica
- https://www.sri.gob.ec/o/sri-portlet-biblioteca-alfresco-internet/descargar/05546998-6f29-4870-be3b-62650f312a6c/XML%20y%20XSD%20Factura.zip
- https://www.w3.org/TR/xmldsig-core/xmldsig-core-schema.xsd
